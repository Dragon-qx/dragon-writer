# Volume Map

## 弧线结构 Arc Structure

第一卷：入门（1-60 章）——外门生活到内门选拔
第二卷：游历（61-130 章）——下山历练，揭开魔教阴谋
第三卷：证道（131-200 章）——正邪大战，证道化神

## 情感曲线 Emotional Curve

期待 → 挫败 → 成长 → 迷茫 → 坚定 → 升华

## 钩子种子与回报图 Hook Seed And Payoff Map

- hook-001（入门承诺）→ 第一卷末回收
- hook-002（苏霜初遇）→ 第二卷中回收

## 人物弧线运动 Character Arc Movement

陆恒：凡人 → 修士 → 宗师 → 证道

## 关系弧线证据 Relationship Arc Evidence

- 陆恒×林逸：陌生邻舍 → 事务搭档 → 经历第一次真实代价后才可进入信任 → 是否成为挚友由后续选择决定。
- 陆恒×苏霜：身份不对等的初识 → 低风险试探 → 互相验证动机 → 共享秘密 / 亲密关系必须分别挣得，不能由“道侣候选”标签提前兑现。

## 故事时间尺度 Story-Time Scale

- 第一卷可覆盖数月至一年；章节按戏剧问题切分，不按自然日切分。
- 训练、旅行与等待优先用概述 / 留白压缩；第一次、失败、代价、揭示与关系转折场景化。
- 每章摘要记录 story_time、elapsed 与 novelty_fingerprint；相邻章节可延续同一分钟，也可有明确锚点地跨越数周。

## 节奏原则 Pacing Principles

用“承诺 → 进展 / 受阻 → 回报 / 后效”形成长短不一的压力周期，不按固定章数机械制造高潮。日常、战斗、调查、关系和后效章节按故事需要组合；连续同类章节允许存在，但目标—阻碍—行动链—结果不能无新增量地复刻。
