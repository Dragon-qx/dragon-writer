# Book Rules

## POV 与叙事距离 POV And Narrative Distance

第三人称限制视角，聚焦主角陆恒。

## 题材规则 Genre Rules

仙侠修真，升级流。

## 硬定局锁 Hard Canon Locks

- 青云门创派祖师为云清子
- 修真境界：炼气 → 筑基 → 金丹 → 元婴 → 化神

## 力量 / 资源 / 时间限制 Power / Resource / Time Limits

- 炼气期无法御剑飞行
- 筑基丹需要 300 下品灵石

## 禁手 Forbidden Moves

- 主角不可越两个大境界击败对手
- 禁止无代价的"忽然顿悟"

## 风格约束 Style Constraints

古白夹杂，对话偏白话。

## 年代约束 Era Constraints

架空古代，称谓参考唐宋。
