# 章首与章末技法（Chapter Openings & Closings）

> 续写 / 改写每章正文前必读。本文件是**正面技法库**：告诉起草者章首怎么开、章末怎么切。style_guide 与审计维 42/43 的负面清单在本文件找到对应的"用什么代替"。

## 核心原则

- **章首的任务是让读者立刻回到戏里，不是帮读者回忆上一章。** 读者记得的比你以为的多；读者不记得的，靠场景内的新线索自然唤起，不靠复述。
- **章末的任务是制造翻页欲**：把能量推到曲线上升沿然后切。总结句是泄压阀——一句章末总结能把整章攒的张力放光。

---

## 章首：三行入戏法则

前三行（约 100 字）内必须落在**正在发生的事**上：有人在做某事、有话正被说出、有异常正被察觉。

**禁手（回顾式承接黑名单）**——以下开头方式命中即审计 warning（维 43）：

- **复述型**：「经过昨夜的事……」「回想起……」「想起白天……」
- **状态总结型**：「此刻的陆恒，心情复杂」「他终于明白了……」
- **时间流水型**：连续多章均以「次日清晨 / 夜色深沉……」+ 环境描写开头
- **承接词型**：以「然而」「不过话说回来」「且说」起头

**前情带入限额**：每章用于回顾前情的文字 **≤2 句**，且必须**夹带新信息**（新反应、新细节、新判断），纯复述即违规。

**物理状态续接**：若开场紧接上章，前三行内须出现至少一个**上章末状态锚点**（人物位置 / 身体姿态 / 服饰 / 物件任一），与 intent 的「前章末状态续接」字段一致——避免"上章他坐在椅子上、本章却已在床上醒来"这类无交代的位置互换。

**续接 vs 跳切**：

| 上一章末形态 | 本章首策略 |
| --- | --- |
| 高张力断点（危机切断 / 反转末句 / 半信息揭示） | **直接续接**同一场景的下一拍（动作 / 对话），中间不加任何叙述过渡 |
| 余韵收束（静默余韵 / 决定未执行） | **直接跳切**到新场景 / 新时间，不写"中间发生了什么"的流水账 |

## 开头类型库（与近 3 章轮换）

| 类型 | 形式 | 适用 |
| --- | --- | --- |
| 对话切入 | 首句即人物台词 | 冲突 / 信息章 |
| 动作切入 | 首句即进行中的动作 | 战斗 / 追逐章 |
| 结果先行 | 先给后果画面，再补因 | 悬念 / 反转章 |
| 反常细节 | 一个不对劲的具体细节 | 悬疑 / 铺垫章 |
| 他者视角 | 配角 / 对手眼中的主角 | 换气 + 侧写章 |
| 感官切片 | 单一感官的具体刺激（声音 / 气味 / 触感） | 氛围 / 喘息章 |

**轮换规则**：起草前先标注近 3 章各章的开头类型（从 `chapter_summaries.md` 或近 3 章正文首段判断），本章开头类型**不得与近 3 章任何一章相同**。类型写进 `chapter-NNNN.intent.md` 的「章首 / 章末」节。

## 章末：断章技法库

| 技法 | 形式 | 适用 |
| --- | --- | --- |
| 危机切断 | 动作 / 威胁到达最高点的那一拍切 | 战斗 / 高潮章 |
| 反转末句 | 最后一句颠覆本章既有认知 | 布局 / 打脸章 |
| 半信息揭示 | 关键信息揭一半，末句停在揭示动作上 | 悬疑 / 探秘章 |
| 决定未执行 | 角色下了决定，切在执行前 | 蓄势章 |
| 新变量闯入 | 新人物 / 新消息在末段闯入 | 过渡 / 转场章 |
| 静默余韵 | 一个具体画面 / 动作收束 | 喘息 / 情感章 |

**断章位**：切在能量曲线的**上升沿**，不切在下降沿。切完之后**不要再写任何一句**。

**禁手（宣布式收束黑名单）**——命中即审计 warning（维 43）：

- **总结本章**：「但这个发现足以让他睡一个好觉」「这一夜，他成长了许多」
- **金句升华**：「命运的齿轮开始转动」「这大概就是成长吧」
- **宣布计划**：「他要做的，就是……」「接下来，该……了」
- **情绪命名**：「心中涌起一股暖流」
- **元数据入正文**：钩子推进、审计结论等账本信息**只进 `chapter_summaries.md` / `pending_hooks.md`，绝不写进正文**（包括斜体附注）。

**喘息章例外**：静默余韵允许一个画面句收束，但必须是**具体可见的画面**（「两人身外的雪，不知何时已经停了」可以），不是**抽象总结**（「他终于安心了」不行）。

## 体裁适配

- **玄幻 / 修真 / 升级流**：章末偏「危机切断」「突破前一拍切」；章首忌连续以打坐 / 起床 / 山门环境开头。
- **都市 / 爽文**：章末偏「反转末句」「打脸前一刻切」；社交场景开头多用对话切入。
- **悬疑 / 推理**：章末偏「半信息揭示」；章首多用结果先行、反常细节。
- **言情 / 情感线**：章末偏「决定未执行」「静默余韵」；张力靠留白，不靠总结。
- **日常 / 种田**：允许静默余韵比例更高，但每 3 章至少一个非余韵断章。

---

## 与审计的关系

- **维 42（跨章重复）**：主代理在审计包中按本文件类型名标注近 3 章与本章的开头 / 收尾类型，连续 3 章同类型 -> fail。
- **维 43（去 AI 味）**：本文件两张禁手黑名单（回顾式承接、宣布式收束）是维 43 的判定细则，命中任意一条 -> warning；命中 ≥2 条 -> fail。
