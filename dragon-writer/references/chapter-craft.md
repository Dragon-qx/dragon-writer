# 章节戏剧单元、叙事时间与断章技法

> 续写 / 改写每章正文前必读。本文件是题材无关的**正面技法库**：决定哪些时刻值得写成场景、章节从哪里开始 / 结束、时间如何压缩，以及信息和关系如何在场景中合法变化。这里的类型是选择工具，不是题材限制或固定公式。

## 核心原则

- **章首的任务是让读者立刻回到戏里，不是帮读者回忆上一章。** 读者记得的比你以为的多；读者不记得的，靠场景内的新线索自然唤起，不靠复述。
- **章末的任务是制造翻页欲**：把能量推到曲线上升沿然后切。总结句是泄压阀——一句章末总结能把整章攒的张力放光。
- **章节是戏剧单元，不是日历单元。** 一章可以只过十秒、延续上一章同一分钟，也可以用概述和留白跨越几年。切章依据是问题、选择、转折或后效，不是“天黑了”。
- **只把有变化的时刻放大成场景。** 等待、赶路、重复训练、例行饮食和睡眠若不产生新压力、选择、关系、信息或代价，就概述或跳过。

## 写前先定：本章为什么存在

chapter intent 中先回答四问，答不出时不要靠增加日程填满篇幅：

1. 本章的核心戏剧问题是什么？
2. 章首谁想要什么，什么在阻止他？
3. 章尾哪项事实、选择、关系、资源或风险已经改变，不能与章首互换？
4. 这一变化与近 5–10 章相比新在哪里？

每个场景至少完成一种变化：目标改变、阻碍升级、信息转移、关系边界移动、代价兑现、因果翻转。一个场景若删掉后其余情节完全不受影响，应合并、概述或删除。

### 场景与反应段的弹性组合

- **行动场景**：目标 → 阻碍 / 冲突 → 结果或局面转向。结果不必总是失败，但必须改变下一步。
- **反应 / 后效段**：感受后果 → 权衡 → 形成新决定。只写到决定或理解改变为止，不把洗漱、吃饭、睡觉自动补齐。
- 两者不是固定交替公式。惊悚、动作可以连续行动；关系、文学、日常可以延长后效；实验叙事可以打破顺序。唯一硬条件是每段有可辨认的功能。

### 描写必须承担任务，不按配额凑数

在 intent 的 `Required Scene Beats` 为每个必要场景写清 `description_obligation`：本场究竟需要让动作空间可读、把情绪变成可观察反应、让环境形成压力、显示关系边界，还是让线索可被公平观察。起草后在 `Draft Evidence Map` 用段落号和正文短引证明它已落实。

- “环境描写”“加强氛围”“多写心理”不是合格职责，必须说明它改变读者对行动、人物或局面的哪项理解。
- 不规定感官数量、景物段数、对话比例或固定句长；机械配额会诱发模板化补水。
- 字数不足时先定位未完成的场景工作，只扩写缺失的冲突过程、选择、后效、动作可读性或关系 / 信息变化。
- 禁止用复述前情、同义心理、无作用景物、重复对话和提前解释后文来填满字符下限。

## 叙事时间：场景、概述、留白

| 模式 | 用法 | 适合 |
| --- | --- | --- |
| scene（场景） | 接近实时，写动作、对话、感官与选择 | 不可替代的冲突、揭示、关系变化 |
| summary（概述） | 用几句或几段压缩重复 / 渐变过程 | 训练、旅程、调查积累、关系缓慢变化 |
| ellipsis（留白） | 直接跳到下一个有效时刻 | 无事件等待、例行生活、故意悬置的过程 |

**进入尽量晚，离开尽量早**：从局面即将失衡的那一拍进入，在结果已改变下一步时离开。不要为了交代人物如何起床、出门、抵达而从清晨开写；也不要为了“完整”补到夜晚入睡。

**跳时落点**：

- 小跳时（分钟到数日）通常用空行、场景分隔或章节分隔即可。
- 中长跳时（数周到多年）在落点尽快给出时间线索、地点和变化后的角色状态，不要求一段百科式总结。
- 跳过的时段若包含会改变角色知识、关系、伤势、资源或身份的事件，必须概述并记入 Runtime；否则不能让变化凭空出现在落点。
- chapter intent 必填章首 / 章末故事时钟、覆盖耗时、每段时间呈现模式和被跳过的时段。

## 章首：三行入戏法则

前三行（约 100 字）内必须落在**正在发生的事**上：有人在做某事、有话正被说出、有异常正被察觉。

**禁手（回顾式承接黑名单）**——以下开头方式命中即审计 warning（维 43）：

- **复述型**：「经过昨夜的事……」「回想起……」「想起白天……」
- **状态总结型**：「此刻的陆恒，心情复杂」「他终于明白了……」
- **时间流水型**：连续多章均以「次日清晨 / 夜色深沉……」+ 环境描写开头
- **承接词型**：以「然而」「不过话说回来」「且说」起头

**前情带入限额**：每章用于回顾前情的文字 **≤2 句**，且必须**夹带新信息**（新反应、新细节、新判断），纯复述即违规。

**物理状态续接**：若开场紧接上章，前三行内须出现至少一个**上章末状态锚点**（人物位置 / 身体姿态 / 服饰 / 物件任一），与 intent 的「前章末状态续接」字段一致——避免"上章他坐在椅子上、本章却已在床上醒来"这类无交代的位置互换。

**续接 vs 跳切**：

| 上一章末形态 | 本章首策略 |
| --- | --- |
| 高张力断点（危机切断 / 反转末句 / 半信息揭示） | **直接续接**同一场景的下一拍（动作 / 对话），中间不加任何叙述过渡 |
| 余韵收束（静默余韵 / 决定未执行） | **直接跳切**到新场景 / 新时间，不写"中间发生了什么"的流水账 |

## 开头类型库（按功能变奏）

| 类型 | 形式 | 适用 |
| --- | --- | --- |
| 对话切入 | 首句即人物台词 | 冲突 / 信息章 |
| 动作切入 | 首句即进行中的动作 | 战斗 / 追逐章 |
| 结果先行 | 先给后果画面，再补因 | 悬念 / 反转章 |
| 反常细节 | 一个不对劲的具体细节 | 悬疑 / 铺垫章 |
| 他者视角 | 配角 / 对手眼中的主角 | 换气 + 侧写章 |
| 感官切片 | 单一感官的具体刺激（声音 / 气味 / 触感） | 氛围 / 喘息章 |

**变奏规则**：起草前标注近 5–10 章的开头类型与戏剧功能。类型可以复用；不能连续复用“同类型 + 同人物动作 + 同信息功能 + 同情绪效果”的组合。动作章连续动作切入完全合法，只要一次是追逃、一次是失败后果、一次是关系冲突，而非同一模板换词。

## 章末：断章技法库

| 技法 | 形式 | 适用 |
| --- | --- | --- |
| 危机切断 | 动作 / 威胁到达最高点的那一拍切 | 战斗 / 高潮章 |
| 反转末句 | 最后一句颠覆本章既有认知 | 布局 / 打脸章 |
| 半信息揭示 | 关键信息揭一半，末句停在揭示动作上 | 悬疑 / 探秘章 |
| 决定未执行 | 角色下了决定，切在执行前 | 蓄势章 |
| 新变量闯入 | 新人物 / 新消息在末段闯入 | 过渡 / 转场章 |
| 静默余韵 | 一个具体画面 / 动作收束 | 喘息 / 情感章 |

**断章位**：切在能量曲线的**上升沿**，不切在下降沿。切完之后**不要再写任何一句**。

**禁手（宣布式收束黑名单）**——命中即审计 warning（维 43）：

- **总结本章**：「但这个发现足以让他睡一个好觉」「这一夜，他成长了许多」
- **金句升华**：「命运的齿轮开始转动」「这大概就是成长吧」
- **宣布计划**：「他要做的，就是……」「接下来，该……了」
- **情绪命名**：「心中涌起一股暖流」
- **元数据入正文**：钩子推进、审计结论等账本信息**只进 `chapter_summaries.md` / `pending_hooks.md`，绝不写进正文**（包括斜体附注）。

**喘息章例外**：静默余韵允许一个画面句收束，但必须是**具体可见的画面**（「两人身外的雪，不知何时已经停了」可以），不是**抽象总结**（「他终于安心了」不行）。

## 信息只能沿可见路径流动

起草对话、推理或行动前，对每名角色做一次“知识快照”：章首知道什么、仍不知道什么、本章会通过哪条路径获得什么。

- 作者、读者、叙事者和角色是四套不同的信息集合。
- 同处一个场景只证明角色有机会观察，不证明听清、理解或知道别人的内心。
- 一条新信息必须通过亲历、被告知、阅读 / 查证、感官观察、可解释推断或已建能力通道进入角色认知，并在正文留下证据。
- 推断只能到证据允许的强度；怀疑不能自动写成确证。
- 信息传递会受到立场、记忆、误解与欺骗影响。必要时让不同角色持有不同版本，而非自动同步为作者真相。

## 关系只能使用已经挣得的权限

关系写法不以“好友 / 恋人 / 敌人”标签代替过程，而看角色此刻实际拥有的权限：如何称呼、能否开私人玩笑、是否可触碰、能否托付、能否披露秘密、是否能替对方做决定。

- 初次见面保留陌生人的信息缺口与边界试探，即使双方强烈吸引或立刻结盟。
- 快速升温可以发生，但必须让共同危机、利益绑定、误认、投射或世界规则等催化器出现在正文，并写出双方不一定对称的反应。
- “像认识多年”不能由旁白直接授予；共同回忆、默契暗号和旧识口吻必须有实际历史。
- 每次关系变化都问：谁先迈步、对方接受还是退缩、这一步付出了什么、下一场互动因此有什么不同。

## 多种热门叙事的可选技法

- **幻想 / 科幻 / 升级叙事**：用“承诺—进展—回报”管理能力、世界谜题与代价；进展必须改变读者对回报的预期，不用重复训练替代成长。
- **悬疑 / 推理**：让关键线索有明确来源，并以公平方式进入读者可见文本；惊讶来自解释变化、注意力误导或偏见，不来自侦探私下获得作者未展示的信息。
- **爱情 / 友情 / 群像**：把关系本身当成一条有目标、阻碍、代价和阶段变化的情节线；吸引、信任、承诺与亲密不是同一层，也不要求双方同步。
- **惊悚 / 动作 / 冒险**：缩短场景与句段可加速，但连续高强度会失去对比；后效章要展示伤势、资源、身份或关系的具体改变。
- **日常 / 种田 / 成长**：细节的价值来自累积变化与选择，不来自完整记录每一天；可用概述展示季节、劳动和关系渐变，把关键第一次、代价和转折场景化。
- **文学 / 实验 / 意识流**：可以弱化外部情节和传统钩子，但仍需有感知、理解、语言结构或关系意义的变化；刻意重复须改变语境或意义。
- **历史 / 社会 / 权谋**：制度与利益链决定人物可做什么、敢说什么、能知道什么；关系亲近不能绕过身份、礼法和信息渠道，除非文本写出破例的代价。

这些是可组合的镜头，不是分类许可。作品可以混合、反转或拒绝任何类型惯例；以 `author_intent.md` 的承诺为准。

## 与审计的关系

- **维 2（叙事时间与章节切分）**：核查 chapter intent 的时间架构、事件时间轴和 `scene / summary / ellipsis` 选择，专门拦截机械“一章一天”。
- **维 9（信息获知链）**：逐角色核对知识快照、获知路径与正文证据。
- **维 27（关系熟悉度与权限）**：逐关系对核对当前权限、跃迁催化和双方后效。
- **维 42（跨章重复）**：主代理用近 5–10 章情节指纹与近似文本报告判事实层重复；这些资料不传给冷读子代理。同类型不是问题，同功能、同行动链、同结果且无新增量才 fail。
- **维 43（去 AI 味）**：本文件两张禁手黑名单（回顾式承接、宣布式收束）是维 43 的判定细则，命中任意一条 -> warning；命中 ≥2 条 -> fail。
