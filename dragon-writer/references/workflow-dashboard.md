# 模式 F：查看进度 / 写作仪表盘

## 触发时机

看进度 / 关系 / 读章节，或打开仪表盘。

## 使用步骤

1. **定位当前书**（若有多本且未指定，让用户选）。
2. **确认 `books/<book-id>/dashboard.html` 存在**：
   - 若不存在，把模板 `assets/dashboard.html` 复制到书文件夹（仅此一次）。
   - 若已存在，**不要覆盖**——模板是通用的，数据在运行时读取。
3. 告诉用户：**直接双击 `dashboard.html` 即可打开仪表盘**，第一次选择书文件夹授权后，权限仍有效时自动重连（IndexedDB 持久化句柄），无需再次选择。建议 Chrome / Edge。

## 仪表盘工作原理（给用户的说明）

- 第一次打开会弹出文件夹选择框，选中本书根目录并授权。
- 授权后仪表盘读取 `book.json` / `chapters/*.md` / `story/*.md`，实时计算并渲染 5 个标签页：
  - **总览**：进度环 + 统计卡 + 当前状态 + 当前焦点 + 最近章节表 + 审计漂移 + 字数趋势 + 文件诊断
  - **设定完成度**：故事框架 / 卷纲 / 规则书 / 当前状态 4 个折叠域，逐域进度条
  - **设定内容**：5 份设定文件（故事框架 / 卷纲 / 规则书 / 当前状态 / 风格指南）原文 Markdown 全文渲染
  - **人物关系**：左侧 `<canvas>` 力导向关系图（主要角色圆形、次要角色方形）+ 右侧角色详情信息板 + 角色卡列表 + 文字关系列表（屏幕阅读器）
  - **章节阅读**：左栏目录 + 右栏 Serif 字体 Markdown 渲染 + 上一章 / 下一章导航 + 搜索（Ctrl/F）+ 导出全本 TXT（纯正文 / 保留 Markdown）
- 句柄记入 IndexedDB；下次打开，权限仍有效时自动重连（"权限仍有效时自动重连"，不承诺永久零交互；权限失效后需用户点击授权）。
- 浏览器不支持 File System Access API 时，提供"兼容模式选择"（`<input webkitdirectory>`）。
- **兼容模式刷新**：当前会话记住了 File[]，刷新后可复用；**页面重开**后 File[] 丢失，需重新选择（兼容模式无持久化句柄）。
- 所有数据均在本地读取，绝不上传；仪表盘不修改任何书文件。
- 安全：CSP 禁止网络连接（`connect-src 'none'`）；Markdown 链接经过协议白名单校验，禁止 `javascript:` / `data:` / `vbscript:` / `file:` 等危险协议；画布平移和缩放当前未实现。

## 何时调用

- **按需**：用户要求看进度 / 仪表盘 / 完成度 / 人物关系 / 读章节时。
- **新建 / 导入时**（模式 A / 模式 C）：确保书文件夹下有一份仪表盘模板（缺失则注入一次）。
- **不要每章重写仪表盘**——它运行时自会读取最新文件，无需重新生成。

报告仪表盘路径与打开方式即可，不要声称"给用户看了仪表盘"。
