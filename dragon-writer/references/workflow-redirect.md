# 模式 D：转向 / 调整方向

## 触发时机

用户说"把焦点拉回来"、"暂停这条支线"、"下一章要写……"、或"换个方向"时使用。

## 步骤

1. **默认不重写整个基础**。
2. **为局部 1–3 章转向更新 `current_focus.md`**。
3. **只为长期性的方向认同变化更新 `author_intent.md`**。
4. **生成一份全新的权威章节意图**（`chapter-NNNN.intent.json`），再用 `render_intent.py` 生成只读 Markdown 视图。
5. **若新需求与 canon 矛盾**：先记录矛盾并向用户确认，再改既有事实。用户明确改 canon 时记录原值、新值、原因和生效章；canon 变更时更新相关状态并创建快照。
6. **转向涉及角色硬数字变更时**（年龄 / 日期 / 尺寸 / 数量）：同步更新角色卡「canon 数字锚点」表（追加带新生效章的行，不改旧行），并确认卡内散文区不再残留旧值——锚点表与散文矛盾即上游错误。
7. **转向涉及信息或关系跃迁时**：先写获知路径 / 催化事件，而不是直接把角色状态改成“知情 / 熟悉 / 信任”。多级跃迁可以保留，但必须同步 intent、事件时间轴、事实表与关系许可账本，并写出双方后效。
8. **拿不准时记录冲突或询问**，不要向 canon 文件随意追加模糊备注。
