# Current State

## 进度
- 当前章节：24
- 主角境界：金丹中期
- 地点：寒山宗·藏经阁（秘密修炼室）

## 地点与时间

大纪九百七十三年·冬至。陆恒已在寒山宗修行四年，身份是外门弟子，夜间潜入藏经阁地下修炼。

## 主角
- 身份：寒山宗外门弟子（实为隐藏身份的复仇者）
- 目标：**近期**：通过宗门大比进入内门，接触更高层信息；**远期**：追查灭门真相、掀翻仙门秩序
- 能力：霜雪之力第三层"凝霜成剑"、自创功法《寒心诀》
- 秘密：母亲是万年前霜神一脉最后的传人

## 已知真相

1. 灭门当晚，屠村者用的是天元宗的"清风剑诀"。
2. 母亲在冰层中给他留了一封信，指向一个叫"寒山遗藏"的地方。
3. 天元宗掌教姬长歌在一千年前曾参与镇压霜神遗脉。
4. 苏晚晴并非真正的天元宗弟子，她的身份另有隐情。

## 关系

- **苏晚晴**：已成恋人，两人互相隐瞒身份。她不知陆恒是霜神遗脉。
- **大师兄周道玄**：失踪，疑似被卷入万年前秘辛。陆恒暗中追查。
- **师父寒山子**：知晓陆恒身份，暗中保护他，但两人从未挑明。
- **姬长歌**：尚未直接交手，但陆恒已从线索中感到对方的可怕。

## 资源 / 伤势 / 库存

- 武器：一柄无名寒铁短剑（母亲遗物）。
- 功法：《寒心诀》（自创、第二层）、《清风剑诀》（偷学，用于掩饰身份）。
- 资源：月俸 30 下品灵石；母亲遗物"冰魄珠"一枚（尚未解开封印）。

## 当前冲突

宗门大比即将开始，胜者可入内门。但内门长老"柳千帆"似乎怀疑陆恒的真实身份，暗中派人监视。同时，陆恒发现大师兄失踪前留下的暗号，指向藏经阁地下的一间密室。
